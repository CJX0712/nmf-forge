    核心递推 乘法更新 = 对步长做「自适应对角缩放」的梯度下降

    目标（Frobenius）F(W,H) = ‖X − WH‖²_F    s.t. W ≥ 0, H ≥ 0
    H 更新H ← H ∘ (WᵀX) ⊘ (WᵀWH)
    W 更新W ← W ∘ (XHᵀ) ⊘ (WHHᵀ)
    目标（KL）D(X‖WH) = Σ X∘log(X⊘WH) − X + WH
    H 更新（KL）H ← H ∘ (Wᵀ(X⊘WH)) ⊘ (Wᵀ1)
    W 更新（KL）W ← W ∘ ((X⊘WH)Hᵀ) ⊘ (1Hᵀ)
    KKT（非负约束）W ≥ 0, ∇_W F ≥ 0, W ∘ ∇_W F = 0（互补松弛）
    为什么单调？ Lee-Seung 的更新来自 majorize-minimize：F 的辅助函数 G(W,Wᵗ) ≥ F(W) 且 G(Wᵗ,Wᵗ)=F(Wᵗ)， 对其最小化得闭式解即上式，于是 F 严格不增。因此「目标函数单调不增」是被证明的性质，可直接当断言用。

    为什么乘法更新保值零元？ 更新形如 W ← W∘(…)，W_ik=0 则永远为 0 —— 这既是优点（保持结构 / 稀疏），也是陷阱（若某行基向量被初始化成全零，该分量永久死亡，故初始化必须保证严格正）。
